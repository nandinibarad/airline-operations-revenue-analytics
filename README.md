# ✈️ Airline Operations & Revenue Analytics

## 📌 Overview

A SQL and Power BI based data analytics project for analyzing airline operations, flight activity, ticket sales, passenger spending, cancellations, delays, and revenue performance.

## 🛠️ Tools Used

- MySQL
- SQL
- Power BI
- DAX

## 🗄️ Database

The project contains 7 relational tables:

- Airlines
- Airports
- Aircrafts
- Flights
- Passengers
- Tickets
- Payments

Dataset contains **10 airlines, 20 airports, 40 aircrafts, 150 flights, 200 passengers, 500 tickets, and 500 payments**.

## 🔍 Analysis

The project analyzes:

- Airline-wise revenue
- Route-wise revenue and ticket volume
- Average ticket prices
- Busiest airports
- Flight cancellations
- Flight delays
- Peak travel months
- Highest-spending passengers
- Cancellation revenue impact

## 📊 Power BI Dashboard

The dashboard provides visual insights into airline revenue, ticket activity, route performance, cancellations, and travel trends.

### Key KPIs

**Total Revenue:** ₹4,065,150  
**Total Flights:** 150  
**Total Tickets:** 500  
**Cancellation Rate:** 9.33%

### Dashboard Visuals

- Revenue by Airline
- Tickets by Airline
- Top 3 Routes by Revenue
- Average Ticket Price by Route
- Flights by Month
